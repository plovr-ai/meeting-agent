## Product Direction

MeetingAgent should focus on an independent macOS app for cross-border managers who attend English or bilingual leadership sync meetings.

The first product wedge is not a browser plugin, not a generic meeting summary tool, and not realtime speech playback. The wedge is a realtime meeting cockpit:

- 70% of the main screen is live bilingual captions.
- 30% of the main screen is meeting goal status, unresolved issues, and suggested follow-up questions.

Users said they will keep this app open during meetings. The core value is therefore in-meeting understanding and guidance:

1. Can I understand what is being said despite the language barrier?
2. Is this meeting progressing toward the goal?
3. What key question should I ask before the meeting ends?

Post-meeting summary and execution artifacts remain important, but they are second priority and should reuse the live goal-tracking state.

## Target User

Cross-border managers in global companies who attend leadership or management sync meetings across English and Chinese-speaking teams.

The strongest confirmed scenario is cross-national leadership or management sync:

- The manager needs to understand English or bilingual discussion in real time.
- The manager has a concrete meeting goal before the meeting starts.
- The manager needs to know whether decisions, owners, timelines, and open questions have actually been closed.
- The manager may need suggested phrasing for follow-up questions during the meeting.

## Validated Pain

The current manual workflow:

1. Take key notes during the meeting.
2. Review meeting playback afterward to fill gaps.
3. Manually extract conclusions, TODO items, and owners.
4. Send the result to others for confirmation.
5. Reconfirm repeatedly when understanding differs.

Target customers confirmed the stronger need is in-meeting assistance:

- Realtime original-language captions.
- Realtime translated captions.
- Goal-based meeting progress tracking.
- Suggested key follow-up questions.

Post-meeting summary is second priority.

## MVP Experience

### Before Meeting

The user should be able to:

- Choose source language, default English.
- Choose target language, default Chinese.
- Enter the meeting goal.
- Enter must-confirm questions.
- Optionally enter names, project names, and terminology.

### During Meeting

The app should show a compact always-available macOS meeting cockpit:

```text
+------------------------------------------------+-------------------------+
| Live Bilingual Captions                         | Meeting Goal            |
|                                                | Status: Partially Done  |
| Speaker A: original English text...            |                         |
| Chinese translation...                         | Confirmed               |
|                                                | - ...                   |
| Speaker B: original English text...            |                         |
| Chinese translation...                         | Unresolved              |
|                                                | - owner not confirmed   |
|                                                | - deadline not confirmed|
|                                                |                         |
|                                                | Suggested Questions     |
|                                                | "Can we confirm..."     |
+------------------------------------------------+-------------------------+
```

Behavior:

- Original captions should appear with lowest possible latency.
- Translation can lag slightly, but should not block original captions.
- Captions should preserve speaker turns when available.
- Goal state should refresh every 30-60 seconds or when clear risks appear.
- Suggested questions should be limited to 1-3 items.
- Suggestions should be copyable.
- Live translation or analysis failure must not stop recording or original captions.

### After Meeting

The app should generate:

- Goal achievement status.
- Confirmed decisions.
- Unresolved issues.
- TODO / owner / deadline.
- Bilingual transcript.
- Chinese alignment summary for local team communication.

## P0 Product Requirements

1. Live bilingual captions are the primary screen.
2. Meeting goal input is required before starting goal analysis.
3. Goal status is structured, not generic summary prose.
4. Suggested questions are low-noise and actionable.
5. Recording and WAV persistence remain independent from live analysis.
6. Post-meeting summary is goal-oriented and derived from transcript plus live progress state.
7. App runs as an independent macOS app, not a browser plugin.

## P0 Technical Requirements

Add or evolve these concepts:

- `MeetingGoal`
- `MeetingObjective`
- `LiveCaptionTurn`
- `TranslatedCaptionStore`
- `MeetingProgressAnalyzer`
- `MeetingProgressState`
- `FollowUpQuestionSuggestion`
- `GoalOrientedSummaryProvider`
- `LiveMeetingDashboardView`

Prioritize:

- Deepgram streaming as the default live STT path.
- Hosted text translation as the default live caption translation path.
- Floating or compact macOS dashboard window behavior.
- Keychain-backed API keys.
- Explicit privacy disclosure for hosted providers.

## What To Deprioritize

Hide or defer these until the live cockpit works:

- Browser plugin.
- Realtime speech playback.
- OpenRouter audio transcription as a primary STT path.
- Local translation provider UI.
- Complex provider profile selection.
- Large export matrix.
- Team/cloud/account features.
- SRT/VTT export.

## Acceptance Criteria

Run a real 30-60 minute English management sync and verify:

- Original captions continue throughout the meeting.
- Chinese translation is readable and latency is acceptable.
- Goal status identifies at least 2-3 unresolved or partially resolved items when present.
- At least one suggested question is useful enough that the user would ask or copy it.
- Recording is preserved even if translation or analysis fails.
- Meeting end produces a goal-oriented summary.
