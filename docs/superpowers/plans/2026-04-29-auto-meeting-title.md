# Auto Meeting Title Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate and persist concise meeting titles after summary generation when the meeting still has a generic app-derived name.

**Architecture:** Extend `MeetingSummary` with an optional generated title, fill it in local and OpenRouter providers, and let `MeetingAgentViewModel.generateSummary(for:)` conditionally save it back to `MeetingRecord.name`. Preserve user-authored names by centralizing a conservative generic-name predicate in the view model.

**Tech Stack:** Swift 5.9, SwiftPM, XCTest, existing `MeetingSummaryProvider` and `MeetingAgentViewModel` boundaries.

---

## File Structure

- Modify `Sources/MeetingAgentCore/MeetingSummary.swift` for the new optional summary field and shared title derivation.
- Modify `Sources/MeetingAgentCore/OpenRouterMeetingSummaryProvider.swift` to prompt for and parse the generated title.
- Modify `Sources/MeetingAgentCore/MeetingAgentViewModel.swift` to persist titles for generic meeting names only.
- Modify `Tests/MeetingAgentCoreTests/MeetingSummaryTests.swift` for Codable compatibility.
- Modify `Tests/MeetingAgentCoreTests/MeetingSummaryProviderTests.swift` for provider title behavior.
- Modify `Tests/MeetingAgentCoreTests/MeetingAgentViewModelTests.swift` for metadata persistence behavior.
